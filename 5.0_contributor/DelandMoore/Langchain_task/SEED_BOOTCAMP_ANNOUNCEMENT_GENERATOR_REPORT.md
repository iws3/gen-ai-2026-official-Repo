## 1. Project Overview

This project is a small Generative AI application that produces SEED Bootcamp announcements in multiple writing styles. It uses LangChain to connect a reusable prompt template, a chat model, and a string output parser.

The application is implemented in `core/Task1.py`. It generates three announcements for the same bootcamp details using formal, friendly, and urgent tones. It then demonstrates token streaming by generating an inspirational version and printing the response as it arrives.

## 2. Project Objective

The objective is to demonstrate how a single LangChain Expression Language (LCEL) chain can be reused with different input values. The project shows how prompt variables make it possible to control:

- The target audience
- The tone of the announcement
- The announcement details
- The way the response is displayed, either all at once or incrementally

## 3. Technologies Used

## 4. Implementation

### Model setup

`core/models.py` contains the reusable `create_model()` function. It loads environment variables from `.env` and initializes the configured chat model with a temperature of `0.5`.

`config.py` defines the model settings. `Task1.py` explicitly selects the Qwen model through the `QWEN` configuration value.

### Prompt template

The prompt in `Task1.py` contains two messages:

1. A system message that defines the model as a professional bootcamp announcement writer.
2. A human message containing the variables `tone`, `audience`, and `announcement_details`.

The prompt is composed into this chain:

```text
ChatPromptTemplate -> chat model -> StrOutputParser
```

### Multiple tone generation

The script stores three tones in a list:

```python
tones = ["formal", "friendly", "urgent"]
```

It loops through the list and invokes the same chain three times. Each result is printed beneath a header showing the selected tone.

### Streaming generation

After the three standard invocations, the script calls `chain.stream()` with the tone set to `inspirational`. Each returned text chunk is printed immediately using `end=""` and `flush=True`, demonstrating incremental model output.

## 6. How to Run the Project

Run the following commands from the `1.8_langchain` directory:

```bash
python -m core.Task1
```

Before running the script, configure the required Groq credentials in a local `.env` file. Do not commit that file to GitHub because it may contain a private API key. The repository `.gitignore` is configured to exclude `.env` files.

The installed dependencies must include the LangChain packages, the selected model provider integration, and `python-dotenv`.
